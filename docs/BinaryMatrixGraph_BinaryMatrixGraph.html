Class: BinaryMatrixGraph

BinaryMatrixGraph(arr, numRows, numCols)

new BinaryMatrixGraph(arr, numRows, numCols)

A grid graph backed by a 2D binary matrix. Nodes are [row, col] pairs, and the grid cell at those coordinates is either open (0) or blocked (1).

Parameters:
Name Type Description
arr Array.<Array.<number>>

The grid as a 2D array of 0 (open) / 1 (blocked).
numRows number

Number of rows in the grid.
numCols number

Number of columns in the grid.
